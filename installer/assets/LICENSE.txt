COMPONENTES DE TERCEROS

Este software utiliza las siguientes librerias de codigo abierto:

- FastAPI (MIT) - Framework web de alto rendimiento para Python
- PyMuPDF / fitz (AGPL v3) - Procesamiento de documentos PDF
- pymupdf4llm (AGPL v3) - Conversion PDF a Markdown
- pdf2docx (MIT) - Conversion PDF a Word
- Pillow (HPND) - Procesamiento de imagenes
- Uvicorn (BSD) - Servidor ASGI de alto rendimiento
- Next.js (MIT) - Framework React para el frontend
- React (MIT) - Libreria de interfaz de usuario
- Tailwind CSS (MIT) - Framework CSS utilitario
- Zustand (MIT) - Manejo de estado global
- Tesseract OCR (Apache 2.0) - Motor de reconocimiento de caracteres
- LibreOffice (MPL 2.0) - Suite ofimatica para conversion de documentos
